# CivicsEdu - Enterprise Learning Platform (Client)

A modern, feature-rich learning platform built with React, Vite, Tailwind CSS, and Redux Toolkit.

## 🚀 Features

- **Beautiful UI** — Modern CivicsEdu-inspired design with dark mode
- **Course Catalog** — Browse, search, filter courses with beautiful cards
- **Course Learning** — Video player, lesson sidebar, notes, discussions
- **Test Series** — Full-screen test taking with timer, navigator, question review
- **Quiz System** — In-course quizzes with instant results
- **Student Dashboard** — Progress tracking, enrolled courses, badges
- **Teacher Dashboard** — Course/test management with CRUD operations
- **Leaderboard** — Weekly/monthly/all-time rankings
- **Achievements** — Badge collection and gamification
- **Wishlist** — Save courses for later
- **Checkout** — Razorpay payment integration with coupon support
- **Real-time** — Socket.IO notifications
- **Dark Mode** — System-aware theme switching
- **Responsive** — Mobile-first design

## 📦 Tech Stack

- **React 18** + Vite
- **Redux Toolkit** (14 slices)
- **React Router v6** (30+ pages)
- **Tailwind CSS** (custom design system)
- **Framer Motion** (animations)
- **Socket.IO Client** (real-time)
- **Recharts** (analytics)
- **React Hot Toast** (notifications)
- **Axios** (API with interceptors & auto refresh)

## 🛠 Setup

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
