# 🛡️ Enterprise Admin Panel

Modern, enterprise-grade admin dashboard for the CivicsHub learning platform.

## Features

- 🎨 **Beautiful Modern UI** - Tailwind CSS with dark mode support
- 📊 **Interactive Dashboard** - Charts, stats, and real-time metrics
- 👥 **User Management** - Full CRUD with role-based filters
- 📚 **Course Management** - Create, edit, publish, feature courses
- 📝 **Test & Quiz Oversight** - Monitor all platform tests and quizzes
- ⭐ **Review Moderation** - Approve, reject, or delete reviews
- 🎓 **Enrollment Tracking** - Progress monitoring with CSV export
- 💰 **Revenue Analytics** - Charts, trends, and financial insights
- 👨‍🏫 **Teacher Management** - Verify and manage teacher accounts
- 📁 **Category Management** - Course and exam category CRUD
- 🎫 **Coupon Management** - Create and manage discount coupons
- 📢 **Announcement Center** - Send notifications to targeted users
- 🔐 **Protected Routes** - Role-based authentication
- 🌙 **Dark Mode** - System-aware with manual toggle
- 📱 **Fully Responsive** - Mobile-first design

## Tech Stack

- **React 18** + Vite
- **Redux Toolkit** for state management
- **Tailwind CSS** with custom design system
- **Recharts** for data visualization
- **Lucide Icons** for consistent iconography
- **React Hot Toast** for notifications
- **Axios** with interceptors for API calls

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
